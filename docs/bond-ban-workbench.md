# 盟约抽选与禁用规则

“其他 → Ban”和“盟约 → 盟约分类与抽选规则”共用分类工作区。上方按分类切换，显示成员数与抽选数；一次只展示当前分类的成员。每个成员卡片直接编辑当前规则，支持名称／ID 搜索和规则筛选。

批量工具栏位于成员列表上方。勾选卡片或全选当前筛选结果后，在同一位置选择规则并应用，不另行重复展示目标名单。搜索隐藏的已选项仍计入批量操作，并显示数量提示；切换分类或赛季会清空本地选择。成员列表独立滚动，工具栏保持在列表外。

类别决定抽选池，规则跟随盟约并在多个分类间共享。核心池存在“抽中保护成员”时，页面列出具体盟约、解释占用名额的影响，并提供只将这些保护项改为“抽中禁用”的操作。单个盟约详情中同样提供提示。不会在加载旧数据时自动改写规则。

添加成员时明确显示“加入时规则”：加入核心类默认选择“抽中禁用全部成员”，其他分类默认保留原规则，也可主动选择其他规则。移除分类成员只改变归类，保留规则；删除自定义分类保留其他分类和盟约规则。忽略、永久免疫和旧抽选排除名单不计入可抽上限；模式名单仍会进一步缩小候选池。

保存字段和 PC／PE 导出结构保持现有 `banConfig.classification` 契约。新旧规则配置继续通过原有目录保存及 JSON 导出路径传递，不要求游戏客户端或服务器升级。
